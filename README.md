# Animated Portfolio

A visually engaging, animated portfolio website to showcase your skills, expertise, and projects at a glance. Designed to impress prospective clients and employers.

## Features

- **Modern Design:** Clean, responsive layout with attractive color gradients.
- **Animated Elements:** Smooth transitions and interactive UI components.
- **Skills Showcase:** Highlights your technical and creative abilities.
- **Project Gallery:** Displays your best work with descriptions.
- **Contact Button:** Easy way for clients to reach out.
